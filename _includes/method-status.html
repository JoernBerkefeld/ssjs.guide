{% comment %} Renders a small INLINE per-method / per-property verification badge, for use next to an individual method/property heading on an in-progress page. Reuses the SAME CSS classes and SVG glyphs as verification-status.html, so no new CSS is needed. Parameters: status (string) - verified | in-progress | blocked | pending verified → runtime-proven (green) in-progress → could not be proven in the current test env yet (yellow) blocked → cannot be used successfully at runtime — either the underlying feature is deprecated / retired, or the member exists but no working invocation could be found (red) pending → not yet checked (grey) differs (bool) - optional; when true, also renders the "Differs from docs" triangle badge (combine with any status). Usage: {% include method-status.html status="verified" %} {% include method-status.html status="in-progress" differs=true %} {% include method-status.html status="blocked" differs=true %} IMPORTANT: This is an INLINE (span) badge often placed on a Markdown heading line. The whole badge is emitted as a SINGLE line with no internal newlines and no leading indentation, using Liquid whitespace-control markers, so Kramdown never sees an indented (4+ space) line and never wraps the SVG/label in an indented code block (highlighter-rouge / pre). {% endcomment %} {%- assign m_status = include.status | default: "pending" -%} {%- if m_status == "verified" -%} {%- assign m_class = "status-verified" -%} {%- assign m_label = "Verified" -%} {%- assign m_title = "This method/property has been runtime-verified with a live SFMC test script." -%} {%- assign m_svg = '' -%} {%- elsif m_status == "in-progress" -%} {%- assign m_class = "status-in-progress" -%} {%- assign m_label = "In progress" -%} {%- assign m_title = "This method/property could not be proven in the CloudPage test environment yet; verification is still in progress." -%} {%- assign m_svg = '' -%} {%- elsif m_status == "blocked" -%} {%- assign m_class = "status-blocked" -%} {%- assign m_label = "Blocked" -%} {%- assign m_title = "This method/property cannot be used successfully at runtime — either the underlying feature is deprecated/retired, or it exists but no working invocation was found. See the note in this section for details." -%} {%- assign m_svg = '' -%} {%- else -%} {%- assign m_class = "status-pending" -%} {%- assign m_label = "Pending" -%} {%- assign m_title = "This method/property has not yet been runtime-verified." -%} {%- assign m_svg = '' -%} {%- endif -%} {%- if include.differs -%} {%- assign m_differs = 'Differs from docs' -%} {%- else -%} {%- assign m_differs = "" -%} {%- endif -%} {{ m_svg }}{{ m_label }}{{ m_differs }}
