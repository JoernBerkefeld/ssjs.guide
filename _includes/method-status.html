{% comment %} Renders a small INLINE per-method / per-property verification badge, for use next to an individual method/property heading on an in-progress page. Reuses the SAME CSS classes and SVG glyphs as verification-status.html, so no new CSS is needed. Parameters: status (string) - verified | in-progress | pending verified → runtime-proven (green) in-progress → could not be proven in the test env / blocked (yellow) pending → not yet checked (grey) differs (bool) - optional; when true, also renders the "Differs from docs" triangle badge (combine with any status). Usage: {% include method-status.html status="verified" %} {% include method-status.html status="in-progress" differs=true %} {% endcomment %} {% assign m_status = include.status | default: "pending" %} {% if m_status == "verified" %} {% assign m_class = "status-verified" %} {% assign m_label = "Verified" %} {% assign m_title = "This method/property has been runtime-verified with a live SFMC test script." %} {% elsif m_status == "in-progress" %} {% assign m_class = "status-in-progress" %} {% assign m_label = "In progress" %} {% assign m_title = "This method/property could not be proven in the anonymous CloudPage test environment; verification is blocked." %} {% else %} {% assign m_class = "status-pending" %} {% assign m_label = "Pending" %} {% assign m_title = "This method/property has not yet been runtime-verified." %} {% endif %} {% if m_status == "verified" %} {% elsif m_status == "in-progress" %} {% else %} {% endif %} {{ m_label }} {% if include.differs %} Differs from docs {% endif %}
